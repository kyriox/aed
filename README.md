# Análisis exploratorio en datos

Este repositorio contiene una colección de cuadernos de Jupyter (`.ipynb`) desarrollados para el curso **Análisis exploratorio en datos**.

## 📁 Contenido del Repositorio

El curso sigue una secuencia lógica para el análisis de datos, partiendo desde los fundamentos hasta algoritmos complejos de agrupamiento:

### Módulo 0: Fundamentos de Python para Análisis
* **00a_intro_python.ipynb**: Introducción a la sintaxis y lógica básica de Python.
* **00b_Funciones_y_Librerías.ipynb**: Creación de funciones y manejo de librerías esenciales del ecosistema científico[cite: 6].
* **00c_ConjuntosYDiccionarios.ipynb**: Uso de estructuras de datos avanzadas para manipulación eficiente de información.

### Módulo 2: Estadística y Proyección
* **01_mediadas_de_tendencia_central.ipynb**: Métodos descriptivos para resumir la distribución de los datos mediante promedios, medianas y centros.
* **02_tecnicas_de_proyección.ipynb**: Técnicas de visualización y reducción de dimensionalidad para datos multivariados.

### Módulo 3: Descubrimiento de Estructuras (Clustering)
* **03_clustering.ipynb**: Guía  sobre algoritmos de agrupamiento y su evaluación. 
* **04_lsa.ipynb**: Introducción al Análisis Semántico Latente para la exploración de datos textuales.

---


## 🛠️ Requisitos

Para ejecutar los cuadernos, se requiere un entorno de Python con las siguientes librerías[cite: 2, 5, 6]:
* `numpy`
* `pandas`
* `matplotlib`
* `scipy`
* `scikit-learn`
